# 数据与隐私

本地书籍、书架、书签和阅读位置保存在设备上。OmiReader 不接入广告、Firebase 分析或性能统计，也不要求注册账号。

普通书籍优先保留系统授权的本地文件引用；DOCX 与 Markdown 转为内部阅读副本，无法保留文件授权时也会复制。虚拟文件夹只保存分类关系，不移动原书。

使用书源搜索、网络书籍、在线朗读、查词、远程书库或 WebDAV 备份时，会连接你设置的对应服务。书源中的规则由导入者选择，服务器能看到完成请求所需的网络信息。

WebDAV 沿用 Legado 的开源实现，使用你配置的地址和账号，没有 OmiReader 中转服务器。

问题记录保存在设备本地。导出、分享或远程备份由你主动操作。
