# 阅读操作

轻点书页中间打开阅读工具；再点面板外的书页即可收起。点击两侧或左右滑动可以翻页，进度会自动保存。

## 底部面板

- **亮度**：拖动横向滑条调节。右侧的 A 图标表示跟随系统亮度；关闭跟随后可以手动调整。
- **快捷操作**：从左到右是全文搜索、自动翻页、替换规则和日间／夜间切换。
- **阅读进度**：拖动进度条跳转，或点击“上一章”“下一章”。章节较多时，可从目录直接定位。
- **目录**：查看章节和书签。
- **排版**：调整字体、字号、行距、段距和页边距。
- **设置**：调整音量键翻页、点击区域、长按选字、屏幕方向等阅读习惯。

## 主题与更多操作

右上角“更多”中可以添加书签、选择阅读主题、开始朗读，以及再次打开这份帮助。四套主题同时调整书架和书页配色，并保留现有的字号、行距与阅读位置。

全文搜索针对本地书籍或已经缓存的正文。朗读可使用设备的语音引擎；在朗读面板中可以调整速度与其他朗读设置。

阅读工具中的修改会自动保存。开启“共用排版”时，各配色沿用同一套文字布局；关闭后可以分别保存不同布局。
