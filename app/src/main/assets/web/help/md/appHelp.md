# 使用 OmiReader

## 导入书籍

在书架点右上角的加号，选择本地文件。也可以在文件管理器中选择“使用 OmiReader 打开”。

## 开始阅读

点击封面打开书籍。文字阅读页的左右区域翻页，点击中间唤出目录、进度、排版与亮度工具。长按文字可以选择、复制和添加书签。

## 调整外观

在书架菜单或设置中打开“阅读主题”，选择雾蓝、北境、暖沙或夜色。字号、行距和页边距在阅读页的排版面板中调整。

## 书源

在“设置 → 书源管理”导入阅读格式的书源 JSON。导入后使用书架菜单中的搜索入口。书源的实际可用性取决于对应网站和规则。

## 备份

在“设置 → 备份与恢复”保存书架、书签与设置。远程同步需要自行配置服务。
