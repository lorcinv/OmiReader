# Data and privacy

Books, library organization, bookmarks and reading positions stay on your device. OmiReader has no advertising SDK or Firebase analytics and does not require an account.

Ordinary local books usually retain a system-authorized file reference. DOCX and Markdown are converted to private reading copies. A copy is also used when a provider cannot retain file access. Virtual folders do not move the original files.

Online book sources, online speech and optional WebDAV backup connect to the service you configure. WebDAV uses the inherited Legado implementation with your own server and account; there is no OmiReader relay server. Local logs are shared or backed up only when you choose to do so.
