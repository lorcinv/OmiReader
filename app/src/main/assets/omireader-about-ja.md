# OmiReader

フォルダー、タグ、しおり、最近読んだ本を備えた端末内の本棚です。ページ中央をタップすると読書ツールが表示されます。組版、ページめくり、全画面表示の設定はすべての本に適用されます。

Omi の霧青、北欧、砂色、夜色の四つのテーマを使用できます。書籍ソースは必要なときに設定から取り込めます。

読書エンジンと書籍ソースエンジンは Legado のリビジョン `da17bb2bed44f30b12a524c2457e32a20b16fa41` を基にしています。gedoor とすべての開発貢献者に感謝します。GPL-3.0 と第三者ライセンスは「オープンソースライセンス」に収録しています。
