# データとプライバシー

書籍、本棚の分類、しおり、読書位置は端末に保存されます。広告 SDK や Firebase 解析は使用せず、アカウント登録も不要です。

通常のローカル書籍は、システムが許可したファイル参照を保持します。DOCX と Markdown はアプリ専用の読書用コピーに変換します。ファイルへの継続アクセスを保持できない場合もコピーを作成します。仮想フォルダーは元のファイルを移動しません。

オンラインの書籍ソース、オンライン読み上げ、任意の WebDAV バックアップは、設定したサービスに接続します。WebDAV は Legado の実装を利用し、自分のサーバーとアカウントに接続します。OmiReader の中継サーバーはありません。端末内のログの共有とバックアップは自分で操作した場合に行います。
